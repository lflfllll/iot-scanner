严重 GoAhead Web 服务器（已知 RCE） WEBSERVER-GOAHEAD · CWE CWE-306 · CVSS 9.8

GoAhead 是大量国产摄像头/DVR 内置的 Web 服务器，CVE-2017-17215 等漏洞允许通过 /SDK/webLanguage 接口未授权执行任意代码，互联网批量利用广泛。

修复建议：立即升级设备固件；关闭 80/8000 端口对不可信网段的访问。
参考: CVE-2017-17215 · CVE-2017-16997

高危 Telnet 服务开放（明文协议） TELNET-OPEN · CWE CWE-319 · CVSS 7.5

Telnet 以明文传输全部流量（含用户名密码），且是 Mirai 等物联网僵尸网络最常攻击的入口。局域网内任意主机均可嗅探凭据。

修复建议：在设备管理界面关闭 Telnet，改用 SSH；如厂商固件不支持，至少设置 16 位以上强密码并禁止 WAN 口访问该端口。
参考: CWE-319 · Mirai 僵尸网络 · CERT VU#630996

高危 RTSP 视频流未授权可播放 RTSP-OPEN · CWE CWE-306 · CVSS 7.5

摄像头 RTSP 流无需认证即可 DESCRIBE/播放，攻击者可直接窃取实时画面，隐私严重泄露。

修复建议：在摄像机设置中开启 RTSP 认证（Digest/Basic），修改默认的 rtsp:// 路径，并限制访问网段。
参考: CWE-306 · OWASP IoT Top-10 I3

高危 已知僵尸网络常用端口开放 BOTNET-PORTS · CWE CWE-668 · CVSS 7.5

2323/48101/34567/37777 等端口是 Mirai、Mozi 等僵尸网络扫描频率最高的端口，常见于被植入远控的木马。

修复建议：检查设备是否已感染僵尸网络（异常外联、固件被篡改）；升级固件、恢复出厂设置并修改全部默认密码。
参考: Mirai · Mozi · CWE-668

中危 管理界面使用未加密 HTTP HTTP-ADMIN · CWE CWE-319 · CVSS 5.9

设备通过明文 HTTP 提供管理页面，同一网络下的攻击者可嗅探登录凭据、篡改页面或实施会话劫持。

修复建议：启用设备 HTTPS 管理（如有），或仅在可信内网访问；修改默认管理端口并启用管理页登录失败锁定。
参考: CWE-319 · OWASP IoT Top-10 I3

中危 DVR/NVR 私有管理端口暴露 DVR-EXPOSED · CWE CWE-668 · CVSS 5.3

大华等 DVR/NVR 私有协议端口开放，历史上存在多起未授权访问与认证绕过漏洞（CVE-2013-6117 等）。

修复建议：升级固件至最新；把 DVR 置于独立网段；关闭不用的 SDK 端口。
参考: CVE-2013-6117 · CWE-668

中危 摄像头嵌入式 Web 服务器 WEBSERVER-CAMERA-WEBS · CWE CWE-306 · CVSS 6.8

修复建议：升级设备固件到最新版本；修改默认口令；必要时关闭 Web 管理。
参考: CWE-306

修复建议：升级固件开启 HTTPS，或将设备置于独立 IoT VLAN 限制访问。
参考: CWE-319
